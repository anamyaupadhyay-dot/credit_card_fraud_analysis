# Credit Card Fraud Analysis | SQL & Excel

## Project Overview
Analyzed credit card transaction data using MySQL and Excel to understand transaction patterns, identify fraudulent transactions, and explore spending behavior.

## Dataset
- **Total Transactions:** 42,308
- **Fraudulent Transactions:** 180
- **Fraud Rate:** 0.43%
- **Total Transaction Amount:** $2,966,148.83

## Tools Used
- MySQL – Data querying and analysis
- Microsoft Excel – Data analysis and reporting

## Key Analysis
- Calculated total transactions, fraud count, and fraud percentage.
- Identified the top 10 most frequently used merchants.
- Analyzed transaction amounts by category and gender.
- Examined transaction dates, locations, and customer spending patterns.
- Identified the day with the highest average transaction amount.

## Key Findings
- 180 out of 42,308 transactions were flagged as fraudulent (0.43%).
- Total transaction value was $2,966,148.83.
- Monday had the highest average transaction amount among the days analyzed.

- `Credit_Card_Fraud_analysis_Portfolio.xlsx` – Excel analysis workbook.
- `Credit_Card_fraud_analysis SQL queries – MySQL queries and analysis.

SQL aggregation, `GROUP BY`, `ORDER BY`, `COUNT()`, `SUM()`, `AVG()`, date functions, fraud analysis, and analytical thinking.
